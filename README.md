Critérios de avaliação

1. Deploy e funcionamento: A aplicação está publicada na Vercel, possui um link de acesso e apresenta integração entre os arquivos
  HTML, CSS e JavaScript.

2. Interatividade sem recarregamento: A aplicação utiliza JavaScript para controlar as interações, incluindo "preventDefault()"
  nos formulários e o gerenciamento de entradas do diário. Também permite a edição e o cancelamento de entradas sem recarregar a página.

3. Persistência de dados: A aplicação utiliza "LocalStorage" para armazenar informações do diário e conversas do assistente virtual,
  permitindo manter os dados disponíveis após atualizar a página.

4. Estabilidade do Console:A aplicação foi desenvolvida buscando garantir estabilidade durante a execução, evitando erros que possam
    comprometer seu funcionamento. Foram realizadas verificações no código JavaScript e na integração entre os arquivos HTML, CSS e
    JavaScript.

5. Adaptabilidade e responsividade: A aplicação utiliza Media Queries no CSS para adaptar a interface a diferentes tamanhos de tela,
    incluindo dispositivos móveis.
